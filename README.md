# Dewfall

Dewfall is an Android app that works like a podcast app for YouTube. You pick channels, and their new videos download overnight while your phone charges on Wi-Fi, so they play instantly the next day, with or without internet. There is no recommendation feed.

**Status:** early development. There is nothing to install yet.
