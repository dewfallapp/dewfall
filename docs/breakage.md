# Breakage

This file is the playbook for when YouTube changes something and Dewfall stops working. It lists the steps to take, in order, and records known problems with specific phone brands.

## Playbook

When the daily check fails or users report that videos stop loading:

1. Confirm the failure on a real phone.
2. Check whether NewPipeExtractor already has a fix.
3. Update the dependency.
4. Run the tests.
5. Ship a hotfix release.
6. Pin a GitHub issue so users know a fix is coming.
