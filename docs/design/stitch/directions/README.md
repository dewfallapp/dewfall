# Stitch directions

In Phase 1, four visual directions were tried in Stitch before one was picked. Each screenshot here shows the inbox in one direction.

- **Baseline:** asked for plain Material 3 defaults, as a control. The result shows standard components and layout, with Stitch's own colors and type. Screenshot: [baseline.png](baseline.png).
- **Reading list:** text-first rows with small thumbnails. Screenshot: [reading-list.png](reading-list.png).
- **Podcast library:** videos grouped by channel. This is the picked direction. Its DESIGN.md and screenshots live one folder up, in [stitch/](../).
- **Quiet cards:** one large thumbnail per card. Screenshot: [quiet-cards.png](quiet-cards.png).

The screenshots in this folder record what was turned down. They may show things Dewfall will not have, such as a profile button or a count badge on the navigation bar.

## Why podcast library

Podcast library was picked because it gives the inbox a structure that matches how the maintainer thinks about channels, and it held up best on the player and subtitle search screens.
