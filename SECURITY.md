# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately, through GitHub's private vulnerability reporting. Never report them in public issues, pull requests or discussions.

To report one:

1. Go to the [Security tab](https://github.com/dewfallapp/dewfall/security) of the repository.
2. Select **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what an attacker could do with it.

Only you and the maintainers can see the report.

## Supported versions

Dewfall has no releases yet. Once it does, this section will list which versions get security fixes.
